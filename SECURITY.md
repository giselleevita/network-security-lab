# Security Policy

## Supported Versions

Security fixes are applied to the `main` branch.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting flow:

https://github.com/giselleevita/network-security-lab/security/advisories/new

Include the affected script or policy, reproduction steps, security impact,
required attacker capabilities, and any suggested mitigation. You should receive
an acknowledgement within seven days.

## Security Scope

This repository is a reproducible hardening lab, not a drop-in production
firewall policy. Validate rules in an isolated environment before deployment.
Production use requires environment-specific segmentation, change control,
monitoring, tested recovery access, and an operational incident-response process.
