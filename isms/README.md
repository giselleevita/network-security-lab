# ISMS — Network Security Controls

This directory documents the Information Security Management System (ISMS) controls implemented in this lab, mapped to **ISO 27001:2022 Annex A**.

## Files

- **`controls.md`** — Full control mapping (A.8.16, A.8.20–A.8.23)
- **`risk-register.md`** — Network-scoped risk register with risk scores and treatment

## Scope

Network security domain — covering perimeter protection, internal segmentation, monitoring, and service security.

## How to Use

This mapping can be used as:
1. Evidence for ISO 27001 certification audits
2. Input to a formal Statement of Applicability (SoA)
3. Reference for gap analysis against existing infrastructure
